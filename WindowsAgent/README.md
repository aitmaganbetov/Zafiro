# Zafiro Agent (Windows)

Программа для ПК клуба: вход клиента, сессии, heartbeat и управление ПК через API zafiro.kz.
WPF + WebView2, .NET 10 (`net10.0-windows`).

## Сборка

- **GitHub Actions** (`.github/workflows/windows-agent.yml`): при каждом изменении `WindowsAgent/`
  в `main` или в pull request собираются установщик и zip-архивы — их можно скачать
  на странице запуска (Artifacts, хранится 30 дней). Запуск вручную — вкладка Actions → Windows agent → Run workflow.
- **Релиз**: каждая сборка `main` (версия `0.0.<номер запуска>`) и тег `agent-v1.0.0` дают GitHub Release
  с установщиком отдельным файлом и `.sha256` (zip-архивы — только в Artifacts). Последний установщик
  всегда по ссылке https://github.com/aitmaganbetov/Zafiro/releases/latest/download/ZafiroAgentSetup.exe —
  её можно указать суперадмину как ссылку на скачивание агента.
- **Локально** (Windows, .NET 10 SDK):
  `dotnet publish WindowsAgent/ZafiroAgent/ZafiroAgent.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=false -p:EnableCompressionInSingleFile=true -o publish` (для маленькой сборки — `--self-contained false` без сжатия)

Каждая сборка даёт установщик и два архива:

| Файл | Размер | Что нужно на ПК |
|---|---|---|
| `ZafiroAgentSetup-<версия>.exe` — **для клубов** | полная сборка + служба | ничего, кроме Windows 10/11 |
| `ZafiroAgent-win-x64-<версия>.zip` | ~60 МБ, .NET внутри | ничего, кроме Windows 10/11 |
| `ZafiroAgent-win-x64-<версия>-small.zip` | ~2 МБ | [.NET Desktop Runtime 10](https://dotnet.microsoft.com/download/dotnet/10.0) (x64) — один раз на ПК; без него Windows сама предложит его скачать |

В обоих случаях на ПК нужен WebView2 Runtime (в Windows 10/11 обычно уже установлен). Рядом с exe
лежат папка `Frontend` (интерфейс агента) и несколько DLL Windows-графики и WebView2 — копируйте
папку целиком.

## Установка на ПК клуба

Обновление: скачайте новый установщик и запустите его на ПК, где агент уже стоит, — установщик сам
находит установленную версию и сразу показывает кнопку «Обновить» (задачи берутся из прошлой установки,
ключ клуба и токен ПК сохраняются).

Скачайте `ZafiroAgentSetup-<версия>.exe` (артефакт сборки или релиз) и запустите его
**от имени администратора**, отметив «Защитить учётную запись клиента». Установщик:
- копирует агент в `C:\Program Files\Zafiro Agent` (клиент не может подменить exe);
- создаёт значок Zafiro Agent на рабочем столе (галочка) и в меню «Пуск», в конце предлагает сразу
  запустить агент;
- регистрирует службу Windows **Zafiro Agent** (SYSTEM, автозапуск). Служба:
  - хранит токен ПК в `C:\ProgramData\ZafiroAgent`, куда у клиента нет доступа (зашифрован ключом
    службы); агент знает только метку, а запросы с токеном (heartbeat, PIN-код, покупка тарифа)
    отправляет служба и только на zafiro.kz. Полученный токен служба сразу меняет на сервере на новый:
    копия, которую видел агент в сеансе клиента, перестаёт работать;
  - раз в минуту отмечает ПК «в сети», даже когда в агенте никто не вошёл;
  - запускает агент при входе клиента и снова через несколько секунд, если агент закрыли или убили;
    агент каждые 5 с сообщает службе, что работает, — зависший или приостановленный агент служба
    перезапускает, а программу с тем же именем не принимает за агент (сверяет путь к exe);
  - не запускает агент в учётных записях администраторов (обслуживание ПК) — если ПК клуба входит
    в Windows под администратором, отметьте в установщике «Запускать агент … и под администратором»
    (значение `LaunchForAdministrators` в `HKLM\SOFTWARE\Zafiro\Agent`); после выхода
    сотрудника по PIN-коду (Ctrl+Alt+P) — время обслуживания из настроек клуба в панели (по умолчанию
    15 минут) или до выхода из Windows. Пока идёт обслуживание (выход по PIN или вход сотрудника на ПК),
    ПК отмечен на карте клуба пунктиром, а в карточке ПК видно, кто и до какого времени;
- запускает `Protect-ClubPc.ps1` для **существующей** учётной записи клиента (`Client` или
  `ZafiroAgentSetup.exe /CLIENTUSER=Имя`) и запрещает ей диспетчер
  задач, редактор реестра, командную строку и скрипты, PowerShell, окно «Выполнить», панель управления,
  MMC, msconfig, mshta, wscript/cscript, а также Game Bar (кнопка Xbox), окна залипания клавиш
  (Shift ×5) и «Ножницы» по PrtScn, смену сетевых настроек (IP-адрес, свойства подключения,
  отключение адаптера); на всём ПК выключает свайпы от края сенсорного экрана. Учётных записей Windows
  ни установщик, ни агент не создают (на супер-рабочей станции новая учётная запись попала бы в образ
  всех ПК). Нет такой учётной записи — запреты пропускаются, служба работает; запустить скрипт для
  нужной учётной записи: `powershell -ExecutionPolicy Bypass -File "C:\Program Files\Zafiro Agent\Protect-ClubPc.ps1" -ClientUser Имя`.

При установленной службе агент всегда работает в режиме киоска: без оплаченной сессии закрыты все
мониторы, а когда сессия заканчивается, клиент выходит из своего аккаунта.

Подключите ПК к клубу **в учётной записи клиента**: служба запустит агент, сотрудник вводит ключ
установки и свой вход, после чего агент сам выходит из аккаунта сотрудника и ждёт клиента.

### Языки (русский, казахский, английский)

Агент показывает язык клуба (настройка клуба в панели); клиент может переключить RU / ҚАЗ / EN
на экране входа и в интерфейсе — после его выхода снова язык клуба. Нет перевода — английский
текст, затем русский. Сообщения сервера приходят на том же языке (заголовок `X-Agent-Locale`).

Тексты — группа `agent` в `database/translations/{ru,kk,en}.php`, ключ — русский текст. После
правки этих файлов выполните `php artisan agent:translations`: она обновит встроенные переводы
`Frontend/i18n/*.json` (агент работает с ними без сети и на бездисковых ПК). Тест
`AgentLocalizationTest` проверяет, что каждый текст из кода агента есть в каталоге и переведён.
Правки суперадмина в «Настройки → Языки» (строки `agent.…`) агенты получают сами: heartbeat
сообщает версию переводов, и агент загружает `GET /api/agent/translations/{locale}`.

### Бездисковая система (CCBoot, iCafeCloud и т. п.)

Всё, что записано на ПК, пропадает при перезагрузке, а образ снят с одного ПК и загружается на всех:
имя ПК, идентификаторы Windows и часто UUID платы у всех ПК одинаковые. Поэтому ПК опознаётся по MAC
активного сетевого адаптера (`MAC-AABBCCDDEEFF`, UUID — только если MAC не определён). Токен ПК привязан
к его MAC: токен, попавший в образ, на других ПК не работает, а служба каждого ПК сама получает токен
своего ПК по ключу клуба (`POST /api/agent/enroll`). Номер ПК, сохранённый в профиле из образа, агент
сбрасывает, если он принадлежит ПК с другим MAC.

1. В режиме обновления образа (супер-рабочая станция) установите агент и подключите ПК к клубу:
   ключ установки и вход сотрудника. Служба запомнит ключ клуба. Сохраните образ.
2. Каждый ПК клуба один раз зарегистрируйте: загрузите его и войдите в агенте сотрудником
   (ПК появится в панели). Регистрация хранится на сервере и после перезагрузки не теряется.
3. Дальше после каждой перезагрузки служба сама получает токен этого ПК; вход сотрудника не нужен.
   Незарегистрированный ПК работает без токена и повторяет попытку раз в 10 минут.

Обновление агента — один раз в образе (шаг 1) и перезагрузка ПК.

На сервере MAC — уникальный ключ ПК в клубе (`AA:BB:CC:DD:EE:FF`): новый MAC — новая карточка ПК,
известный MAC — только своя карточка. Агент никогда не меняет MAC у существующей карточки (heartbeat
с другим MAC игнорируется и пишется в системный лог); перенести MAC на другую карточку может только
сотрудник: «Карта клуба → Редактировать компьютер → MAC-адрес».

Ключ клуба хранит только служба (`%ProgramData%\ZafiroAgent`, доступ — SYSTEM и администраторы).
В профиле клиента вместо него метка, а вход клиента идёт через службу: она подставляет ключ сама.
Без службы (агент из zip) ключ, как раньше, хранится в профиле.

Обновление — новый установщик поверх старого. Удаление — «Приложения» Windows: служба, агент и токен ПК
удаляются (учётная запись `Client` и запреты остаются; снять их: `Protect-ClubPc.ps1 -Undo`).
Подключить ПК к другому клубу: удалить и установить агент заново.

Без установщика (из zip-архива): `powershell -ExecutionPolicy Bypass -File .\Protect-ClubPc.ps1 -AgentPath .`
от имени администратора — скрипт так же ставит агент и службу.

## Структура

- `ZafiroAgent/` — приложение (WPF + WebView2).
- `Frontend/` — интерфейс окна (HTML/JS/CSS); при сборке копируется в `Frontend/` рядом с exe.
- `ZafiroAgent.Tests/` — тесты (xUnit), запускаются в GitHub Actions перед публикацией.
- `ZafiroAgent.slnx` — решение для Visual Studio.

## Как агент работает с сервером

- Сотрудник клуба один раз входит на ПК (ключ установки + свой логин): сервер регистрирует ПК и
  выдаёт **токен устройства**. Heartbeat идёт с ним (`POST /api/agent/heartbeat`, заголовок
  `X-Agent-Token`) и действует только для этого ПК.
- Оплаченной сессией управляет только сервер: время окончания приходит в ответе heartbeat; после
  перезапуска агент восстанавливает сессию, по окончании времени завершает её и возвращает окно поверх
  рабочего стола. «Вернуться на рабочий стол» работает только во время оплаченной сессии.
- При закрытии агента выходит только пользователь; клуб, ключ установки и токен устройства сохраняются.
- Логи: `%LOCALAPPDATA%\ZafiroAgent\logs\agent-ГГГГММДД.log` (7 дней, пароль/ключи/токены замаскированы).
- DevTools (F12) работают только в Debug-сборке.

## Режим киоска

Включается на ПК, который настроил сотрудник (есть токен устройства):

- **Ctrl+Alt+P** — окно PIN-кода сотрудника. PIN задаётся в панели: «Настройки → Настройка клуба →
  PIN-код для выхода из агента» и проверяется на сервере (5 попыток за 5 минут на ПК).
  Только верный PIN закрывает агент; Alt+F4 и «Выход» в трее тоже открывают окно PIN.
- Без оплаченной сессии агент поверх всех окон, заблокированы Win, Alt+Tab, Alt+Esc, Ctrl+Esc, Alt+F4,
  Alt+Пробел и клавиша меню. Во время сессии клавиши работают как обычно.
- Диспетчер задач (Ctrl+Shift+Esc и пункт в Ctrl+Alt+Del) отключён, пока агент работает;
  включается снова после выхода по PIN. Само сочетание Ctrl+Alt+Del Windows перехватить не даёт.
- Агент добавляется в автозапуск текущего пользователя Windows.

Настройки агента на ПК хранятся в `%APPDATA%\ZafiroAgent\agent.config.json`, ключ клуба и токен —
зашифрованы DPAPI. В репозиторий не добавлять `bin/`, `obj/`, `*.user`, сертификаты и сохранённые
ответы сервера — они перечислены в `.gitignore`.
